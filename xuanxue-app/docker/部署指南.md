# Docker 一键部署指南

## 📋 前置要求

### 1. 安装 Docker
- **Windows**: 下载并安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- **Linux**: 
  ```bash
  curl -fsSL https://get.docker.com | bash
  ```
- **macOS**: 下载并安装 [Docker Desktop for Mac](https://www.docker.com/products/docker-desktop/)

### 2. 安装 Docker Compose
- Docker Desktop 已包含 Docker Compose
- Linux 单独安装：
  ```bash
  sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
  sudo chmod +x /usr/local/bin/docker-compose
  ```

### 3. 验证安装
```bash
docker --version
docker-compose --version
```

## 🚀 快速部署步骤

### 步骤 1: 进入项目目录
```bash
cd C:\Users\thor.wen\xuanxue-app\docker
```

### 步骤 2: 启动所有服务
```bash
docker-compose up -d
```

**参数说明：**
- `-d`: 后台运行（detached mode）
- `--build`: 强制重新构建镜像（首次运行或代码更新后使用）

**首次部署建议：**
```bash
docker-compose up -d --build
```

### 步骤 3: 查看服务状态
```bash
docker-compose ps
```

**预期输出：**
```
NAME                 STATUS          PORTS
xuanxue-backend      Up              0.0.0.0:8080->8080/tcp
xuanxue-frontend     Up              0.0.0.0:80->80/tcp
xuanxue-mysql        Up              0.0.0.0:3306->3306/tcp
xuanxue-redis        Up              0.0.0.0:6379->6379/tcp
```

### 步骤 4: 查看日志
```bash
# 查看所有服务日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f backend
docker-compose logs -f frontend
docker-compose logs -f mysql
```

## 🔧 常用操作命令

### 启动服务
```bash
docker-compose up -d
```

```bash

```

### 停止并删除容器


```bash

```

### 重启特定服务
```bash

```

### 查看服务状态
```bash
docker-compose ps
```

### 查看实时日志
```bash
docker-compose logs -f backend
```

```bash

# 进入MySQL容器
```

## 🐛 故障排查

### 问题1: 端口被占用
**错误信息**: `Bind for 0.0.0.0:8080 failed: port is already allocated`

**解决方案**:
```bash
# 查看占用端口的进程
netstat -ano | findstr :8080  # Windows
lsof -i :8080                 # Linux/Mac

# 修改 docker-compose.yml 中的端口映射
ports:
  - "8081:8080"  # 改为其他端口
```

### 问题2: 数据库连接失败
**错误信息**: `Communications link failure`

**解决方案**:
```bash
# 1. 检查MySQL容器是否启动
docker-compose ps mysql

# 2. 查看MySQL日志
docker-compose logs mysql

# 3. 等待MySQL完全启动（首次启动需要时间）
docker-compose logs -f mysql
# 看到 "ready for connections" 表示启动完成

# 4. 重启后端服务
docker-compose restart backend
```

### 问题3: 前端无法访问后端API
**错误信息**: `502 Bad Gateway`

**解决方案**:
```bash
# 1. 检查后端服务状态
docker-compose ps backend

# 2. 查看后端日志
docker-compose logs backend

# 3. 检查网络连接
docker network ls
docker network inspect xuanxue-app_xuanxue-network
```

### 问题4: 构建失败
**错误信息**: `failed to solve: failed to fetch`

**解决方案**:
```bash
# 1. 清理Docker缓存
docker system prune -a

# 2. 使用国内镜像源（可选）
# 在 Dockerfile 中添加镜像源配置

# 3. 重新构建
docker-compose build --no-cache
```

### 问题5: 容器启动后立即退出
**解决方案**:
```bash
# 1. 查看容器日志
docker-compose logs backend

# 2. 检查启动命令
docker-compose config

# 3. 手动启动容器调试
docker run -it --rm xuanxue-backend sh
```

## 🔄 更新部署

### 更新代码后重新部署

## 🔐 生产环境配置

### 修改默认密码
编辑 `docker-compose.yml`，修改以下环境变量：

```yaml
environment:
  - DB_PASSWORD=你的强密码
  - MYSQL_ROOT_PASSWORD=你的root密码
  - MYSQL_PASSWORD=你的数据库密码
  - JWT_SECRET=你的JWT密钥
```

### 配置SSL证书
1. 将SSL证书文件放到 `docker/ssl/` 目录
2. 修改 `nginx.conf` 添加SSL配置
3. 重新构建前端镜像

### 限制资源使用
在 `docker-compose.yml` 中添加资源限制：

```yaml
services:
  backend:
    deploy:
      resources:
        limits:
          cpus: '1'
          memory: 1G
        reservations:
          cpus: '0.5'
          memory: 512M
```
