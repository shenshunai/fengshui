# 玄学应用平台 - 项目设计文档

## 一、项目概述

### 1.1 项目目标
创建一个集星座运势、八字算命、风水测算、起名服务、抽签占卜于一体的现代化玄学应用平台，结合AI技术提供个性化、精准的命理服务。

### 1.2 核心功能
- **星座运势**: 每日/每周/每月运势分析
- **八字排盘**: 精准八字命理分析
- **风水测算**: 家居风水布局分析
- **起名服务**: AI智能起名推荐
- **抽签占卜**: 观音灵签、月老签等

## 五、核心算法

### 5.1 八字排盘算法

#### 年柱计算
```java
// 公元4年为甲子年
int ganIndex = (year - 4) % 10;  // 天干索引
int zhiIndex = (year - 4) % 12;  // 地支索引
```

#### 月柱计算
```java
// 月支固定：正月寅、二月卯...
// 月干根据年干推算（五虎遁口诀）
// 甲己之年丙作首，乙庚之年戊为头...
int zhiIndex = (month + 1) % 12;
int[] monthGanStart = {2, 4, 6, 8, 0}; // 丙戊庚壬甲
int startGan = monthGanStart[yearGanIndex % 5];
int ganIndex = (startGan + month - 1) % 10;
```

#### 日柱计算
```java
// 以1900年1月1日（甲戌日）为基准
LocalDate baseDate = LocalDate.of(1900, 1, 1);
long daysDiff = ChronoUnit.DAYS.between(baseDate, birthDate);
int ganZhiIndex = (10 + daysDiff) % 60;  // 10是甲戌在60甲子中的索引
```

#### 时柱计算
```java
// 时支：23-1子时，1-3丑时...
// 时干：五鼠遁（甲己还生甲）
int zhiIndex = (hour + 1) / 2 % 12;
int[] hourGanStart = {0, 2, 4, 6, 8}; // 甲丙戊庚壬
int startGan = hourGanStart[dayGanIndex % 5];
int ganIndex = (startGan + zhiIndex) % 10;
```

## 六、部署说明

### 6.1 开发环境启动

#### 后端启动
```bash
cd backend
mvn spring-boot:run
```
访问: http://localhost:8080/swagger-ui.html

#### 前端启动
```bash
cd frontend
npm install
npm run dev
```
访问: http://localhost:5173

### 6.2 Docker部署

```bash
cd docker
docker-compose up -d
```

服务访问:
- 前端: http://localhost
- 后端API: http://localhost:8080
- H2控制台: http://localhost:8080/h2-console

### 6.3 生产环境配置

1. 修改 `application.yml` 中的数据库配置
2. 配置 SSL 证书
3. 设置环境变量:
   - `DB_HOST`: 数据库地址
   - `DB_PASSWORD`: 数据库密码
   - `JWT_SECRET`: JWT密钥
   - `REDIS_HOST`: Redis地址
